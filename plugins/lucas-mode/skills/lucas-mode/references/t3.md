# T3 discovery and invocation

Observed in the installed T3 Code Nightly bundle on 2026-10-13, in `src/provider/Drivers/ClaudeSkills.ts`, `ClaudeSkillDispatch.ts`, the Codex app-server probe, and `packages/provider-cursor/src/server/skills.ts`. Re-check the active version when diagnosing different behavior.

- **Codex.** T3 asks the selected Codex binary's native app-server for `skills/list` with the effective cwd. Project `.agents/skills/<name>/SKILL.md` is the discovery location. The observed Codex CLI skips symlinked skill directories and roots. This repository's `scripts/sync.py` generates real project files from the maintained `plugins/lucas-mode/skills` folders and `--check` detects drift. `$name` is a native skill mention. A different profile, disabled skill, cwd, or higher-precedence copy can change discovery.
- **Claude Code.** T3 reads the effective Claude config directory's `skills` and the cwd's `.claude/skills`, rather than `.agents/skills`. Project `.claude/skills/<name>` links in this repository point to the maintained plugin folders. T3 dispatches a known `$name` as `/name` in the final text block. With multiple mentions, the last expands directly; earlier mentions become inline slash references. User copies win same-name collisions. Local and managed overrides can disable invocation.
- **Cursor.** The observed driver scans project and user `.cursor/skills`, `.agents/skills`, `.codex/skills`, and `.claude/skills`, deduplicating by name. It rewrites known `$name` mentions to `/name`. A missing skill stays literal.
- **Other providers.** Do not generalize the paths above. Inspect their driver and run their discovery before claiming support. Antigravity's observed driver accepts project `.agents/skills` but does not read user-global `~/.agents/skills`.

Install the three sibling folders together so cross-skill paths resolve. Keep folder and frontmatter names identical and descriptions valid YAML. Read the returned path and enabled state, not just the name in a picker. Test from the actual worktree, including a nested cwd if that is how the project runs. Relative links must resolve after copying or creating a worktree.

For a compatibility claim, exercise the relevant integration path: native discovery, mention dispatch, then a bounded invocation against harmless local artifacts. A dispatch unit test proves routing only. It does not prove that a remote T3 turn loaded the body or followed it. Report that distinction.
